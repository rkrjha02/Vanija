# Cancellation Policy

> MADE-UP EXAMPLE for testing this project. Edit before any real use.

## Cancelling before the order ships
You can cancel an order at any time before it ships. Ask in the chat and tap the "Yes, cancel order" button to confirm. Cancellation is free.

## Cancelling after the order ships
A shipped order cannot be cancelled. You can refuse the package at the door, or return the product under the returns policy.

## Refunds for cancelled orders
Cash on Delivery orders are paid only at delivery, so a cancelled order needs no refund.

## Cancellations by the store
We may cancel an order if a product becomes unavailable or the delivery address is incomplete. We will tell you if this happens.
